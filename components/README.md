# 🧩 Кастомные компоненты

В эту папку складываются **внешние (кастомные) компоненты ESPHome**,
которые нужны для проекта.

## Что здесь может лежать

- Готовые компоненты из других репозиториев (со ссылкой на источник)
- Собственные компоненты (написанные под конкретный датчик/устройство)
- Примеры кастомных сенсоров, платформ и т.п.

## Что здесь есть сейчас

Пусто — этот шаблон универсальный. Если в твоём проекте не нужны
кастомные компоненты — просто удали эту папку.

## Как подключить

В `esphome/main.yaml` добавь:

    external_components:
      - source:
          type: local
          path: ../components

Замени `../components` на правильный путь, если структура другая.
