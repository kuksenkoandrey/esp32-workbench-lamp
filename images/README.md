# 📸 Изображения

В этой папке лежат фотографии и скриншоты проекта.

## Что сюда можно положить

- Фото собранного устройства (спереди, сзади, сбоку)
- Фото внутренностей (как всё уложено)
- Фото корпуса
- Скриншоты из Home Assistant
- Скриншоты работы устройства

## Что здесь есть сейчас

Пусто — этот шаблон универсальный. Фотографии добавляются по мере наполнения проекта.
